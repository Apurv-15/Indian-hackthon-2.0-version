# 🛡️ AegisAI Browser Extension

Manifest V3 browser extension providing real-time multi-agent phishing protection, domain spoofing analysis, and e-commerce store trust evaluation.

## Features
- **Real-time Link Inspection**: Hover over any hyperlink to trigger zero-overhead cached threat evaluation.
- **Store Trust Engine**: Analyzes e-commerce websites for brand impersonation, high-risk discounts, missing contact signals, and sketchy checkout behaviors.
- **Visual Safety Badges**: Floating UI indicators for instant verdict recognition (Safe, Caution, High Risk).
- **Navigation Interception**: Proactively halts requests to verified malicious destinations and prompts user confirmation.
